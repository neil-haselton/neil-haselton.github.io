# FRC 2026 Robot image guide

All seven original PNG files are preserved in `originals/` with their supplied filenames. Each image also has a website-ready copy in `cropped/`. Every cropped copy uses the same 1600 × 1200 crop from the original canvas (left 850, top 680), so the comparison images remain aligned and the subsystem layers keep their shared camera position.

## Images used on the page

- Project overview: `main-image.jpg` (the supplied competition photo)
- Subsystem explorer default view: `cropped/26-comp-full-detail.png`
- Subsystem explorer ghost view: `cropped/26-comp-full-detail-transparent.png`
- Chassis highlight: `cropped/26-comp-full-detail-chassis.png`
- Intake highlight: `cropped/26-comp-full-detail-intake.png`
- Launcher highlight: `cropped/26-comp-full-detail-turret.png`
- Design Process slider: `cropped/26-comp-block.png` and `cropped/26-comp-full-detail.png`

`cropped/26-comp-full-detail-indexer.png` is stored for a later section but is not currently shown on the page.

The two supplied iteration photos are stored as `iteration-1.jpg` and `iteration-2.jpg`. They appear beside the Iteration text in the same section, with image 1 above image 2.
